## C로 공부한 자료구조

인프런의 「정혜경 판타스틱 자료구조 in C」를 들으며 자료구조를 공부했습니다. 강사님이 설명한 뒤 직접 작성해 보라고 하면 강의를 멈추고 먼저 코드를 짜 보았습니다. 그다음 강사님의 코드와 비교하며 강의를 이어 들었습니다.

이 페이지에는 그때 다룬 자료구조와 실습 내용을 정리했습니다. 배열과 연결 리스트로 구현했을 때 무엇이 달라지는지, 데이터를 넣거나 지울 때 어떤 값을 바꿔야 하는지를 중심으로 정리합니다. 강의에서 들은 설명과 직접 작성한 코드를 연결해 보는 방식입니다.

### 배열과 연결 리스트

배열은 인덱스로 원소의 위치를 찾습니다. 연결 리스트는 노드에 데이터를 담고, 포인터로 다음 노드를 찾아갑니다. 포인터에는 다른 데이터가 놓인 메모리 위치가 들어 있습니다.

단일 연결 리스트는 다음 노드로 이어지는 연결을 관리합니다. 이중 연결 리스트는 이전 노드와 다음 노드의 연결을 함께 관리합니다. 노드를 지울 때는 메모리를 해제하기 전에 주변 노드의 연결부터 바꿔야 합니다.

### 스택과 큐

스택은 마지막에 넣은 데이터를 먼저 꺼내고, 큐는 먼저 넣은 데이터를 먼저 꺼냅니다. 스택의 top과 큐의 front, rear가 각각 어디를 가리키는지 구분하며 코드를 봅니다.

둘 다 배열과 연결 리스트로 구현하는 방법을 다뤘습니다. 배열 원형 큐에서는 배열 끝에 도달한 인덱스를 처음으로 돌려보냅니다. 이때 큐가 비었는지 가득 찼는지도 구분해야 합니다.

### 트리와 힙

트리는 데이터를 부모와 자식 관계로 연결한 구조입니다. 이진 트리의 노드는 자식을 최대 두 개 가집니다. 이진 탐색 트리에서는 값을 비교해 왼쪽이나 오른쪽 자식으로 내려가며 데이터를 찾습니다.

실습에는 전위, 중위, 후위 순회와 노드 검색 및 삭제가 있습니다. 순회는 정해진 순서대로 노드를 방문하는 과정입니다. 힙에서는 데이터를 넣거나 꺼낸 뒤 부모와 자식 사이의 순서가 맞도록 데이터를 위아래로 옮깁니다.

### 그래프와 해시 테이블

그래프는 대상을 나타내는 정점과 그 사이의 관계를 나타내는 간선으로 이루어집니다. 인접 행렬은 정점 사이의 연결을 표에 저장하고, 인접 리스트는 각 정점에 연결된 이웃을 목록에 저장합니다. 실습 코드에는 깊이 우선 탐색과 너비 우선 탐색이 있습니다.

해시 테이블은 해시 함수로 데이터를 저장할 위치를 계산합니다. 서로 다른 데이터의 저장 위치가 겹치는 경우를 충돌이라고 합니다. 실습에서는 같은 위치에 대응하는 데이터를 연결 리스트로 이어 두는 체이닝 방식을 다뤘습니다.

## 응용 실습

### 단어 수 세기

파일에서 읽은 단어를 연결 리스트에 저장하고 정렬한 뒤 단어 수를 세는 예제입니다. 파일 입력과 연결 리스트를 함께 사용합니다.

### 편집기

두 스택에 커서 왼쪽과 오른쪽의 문자를 나누어 담는 예제입니다. 커서를 옮길 때 문자를 한쪽 스택에서 꺼내 다른 쪽 스택에 넣습니다. 스택의 동작을 커서 이동에 연결해 볼 수 있습니다.

### 조세퍼스 순열

정해진 간격마다 사람을 제거하는 과정을 큐로 구현한 예제입니다. 큐 앞에서 꺼낸 데이터를 뒤에 다시 넣는 일을 반복해 순서를 돌립니다.
